﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿桌面歌词 · 使用说明
==================================================

【这是什么】
  一个悬浮在桌面上的歌词组件。它会自动读取你正在使用的音乐软件播放的歌曲，
  在桌面上显示专辑封面、歌名歌手、播放进度，以及带逐字高亮动画的歌词。
  它是一层透明悬浮窗，不会改动你的壁纸。

  支持任何向 Windows 报告播放状态的播放器，实测可用：
    QQ音乐、酷狗音乐、网易云音乐、酷我音乐、Spotify、PotPlayer、foobar2000 等。
  也就是你平时常用的音乐软件基本都能用，不需要额外设置。

【怎么用】
  1. 双击安装程序，一路「下一步」装好（不需要管理员权限）
  2. 打开你的音乐软件播放任意歌曲，歌词会自动出现
  3. 左键任意位置拖动，可以把它放到桌面任何地方（位置会自动记住）
  4. 右键打开设置菜单

【怎么升级】
  程序会自己检查更新：发现新版本后，右键菜单和设置页会显示常驻提示，
  打开提示卡点「立即更新」，它会自动下载、安装并重新打开，
  你什么都不用管。设置、字体、窗口位置都会保留。

  想手动查就点「检查更新…」；想换更新源就点「设置更新源…」。

【右键菜单里有什么】
  · 显示歌词 / 显示播放器：
      只勾歌词 —— 歌名 + 作者 + 播放热度 + 歌词，透明浮在壁纸上
      只勾播放器 —— 唱片 + 歌名 + 音波 + 播放进度 + 控制按钮
      两个都勾 —— 两扇独立窗口，可以分别拖到任意位置
      两个都不勾 —— 桌面不显示，程序继续留在托盘
  · 唱片样式：圆形唱片 / 封面 + 唱片 / 黑胶（带唱臂）/ 经典（方块 + 菱形）
  · 跟随音乐：同时开了多个音乐软件时，指定要跟随哪一个（默认自动）
  · 主题配色：极光、樱花、落日、青竹、素白
  · 歌词字号、字间距、封面大小、播放器宽度
  · 歌词列表行数（1 / 3 / 5 / 7 / 9 / 11 行）、歌词行间距
  · 歌词排版：向左对齐 / 居中 / 向右对齐
  · 整体不透明度
  · 歌词字体：内置「得意黑」和「霞鹜漫黑」，装上就能用，不用联网下载；
    也支持「导入字体文件…」——把自己下载的 ttf / otf / ttc 字体导进来，
    之后一直出现在菜单里；还能从系统字体里挑
  · 文字立体倾斜：上下、左右两个方向可各自调节，还能整体旋转
    （歌词面板和分离面板里的歌词都适用）
  · 歌词同步：可以直接输入毫秒数，也保留提前 / 延后 0.5 秒快捷按钮
  · 锁定位置、鼠标穿透、置顶显示
  · 打开音乐软件时自动显示歌词（默认开）
  · 检查更新
  · 开机自启
  · 最小化到托盘

【检查更新怎么用】
  右键菜单 → 检查更新…，程序会去你指定的「更新源」读最新版本号：
    · 已经有新版本 → 菜单和设置页显示常驻提示，不再弹新版对话框
    · 已经是最新的 → 告诉你当前就是最新
    · 第一次用会先让你填更新源（也随时可以点「设置更新源…」改）

  更新源支持四种写法：
    · GitHub 仓库：   someone/LyricDesk
    · 码云仓库：      gitee:someone/LyricDesk      （国内直连可用，推荐）
    · JSON 链接：     https://你的域名/update.json
    · 本地文件：      D:\LyricDesk\update.json

  JSON 长这样（字段名也兼容 GitHub / Gitee Releases 原生写法）：
    {"version": "1.6.0", "notes": "改了什么", "url": "下载页地址"}

  填好更新源之后，程序每次启动会静默查一次（24 小时内只查一次），
  只有真的出了新版本才显示小点，不会打扰你。

【快捷键与救急】
  · Ctrl + Alt + L ：随时开启 / 关闭鼠标穿透
  · 开启鼠标穿透后会弹出系统通知；如果你在任务栏右下角找不到音符图标，
    点一下「^」展开被折叠的图标，右键它就能改设置

【常见问题】
  问：双击了没反应？
  答：第一次启动需要 2~3 秒，稍等一下。程序启动后不会弹窗口，
      而是直接出现在桌面下方；右下角托盘区会有一个音符图标。

  问：不显示歌词？
  答：确认音乐软件正在播放。歌词和封面需要联网获取，第一次播放某首歌
      可能需要一两秒。软件会依次在 QQ音乐、酷狗、网易云三个曲库里找最
      匹配的歌词，中文歌覆盖很全。

  问：开着音乐软件，桌面却提示「未检测到正在播放的歌曲」？
  答：不少音乐软件的「系统播放控件 / 媒体控制」默认是关的，关掉之后
      Windows 里就没有任何播放信息，任何歌词插件都读不到。请到音乐软件的
      设置里打开它：网易云 → 设置 → 常规 → 系统媒体控制（或「桌面歌词 /
      任务栏播放控制」）；酷狗、QQ音乐 等也有类似开关，名字大同小异。

  问：同时开了好几个音乐软件，它跟错人了？
  答：右键 → 跟随播放器，指定一个；想恢复自动就选「自动（正在播放的那个）」。

  问：歌词比声音快 / 慢？
  答：右键 → 歌词同步，用「提前」「延后」微调，设置会被记住。

  问：怎么关掉？
  答：右键 → 退出，或者右键点击右下角托盘图标 → 退出。

  问：杀毒软件报警？
  答：这是 PyInstaller 打包的 Python 程序，部分杀软会对这类自解压程序
      误报。程序不收集任何个人信息，源码可查。

【系统要求】
  Windows 10 1809 或更高版本（Windows 11 最佳）
  需要能上网（用于获取歌词与专辑封面）

【卸载】
  直接删除这个文件夹即可。
  如果开启过「开机自启」，请先在右键菜单里关掉再删除。
  配置与缓存放在 %APPDATA%\LyricDesk 目录（里面只有设置和歌词/封面缓存），
  想彻底清理可以一并删除。
