﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿﻿桌面歌词 · 更新说明
==================================================

v1.6.8  (2026-10-25)

  【歌词 / 播放器拆成两个独立开关】
    · 「显示歌词」「显示播放器」可以单独开、同时开，也可以都关掉只留托盘。
    · 去掉立体卡片和界面模式；唱片样式合并为：
      圆形唱片 / 封面 + 唱片 / 黑胶（带唱臂）/ 经典（方块 + 菱形）。
    · 老配置会自动迁移：原来的分离面板仍显示两扇窗口，
      立体卡片的经典 / 黑胶 / 封面 + 唱片会迁移成对应唱片样式。
    · 关掉播放器时不会偷偷改掉你原来的进度条、音波或控制按钮设置。

  【更新提示不再弹新版对话框】
    · 发现新版本后，右键菜单显示「● 发现新版本」，
      设置页「更新与关于」显示常驻提示卡和立即更新按钮。
    · 「已是最新」「检查失败」仍然保留明确反馈。

  【设置窗口与歌词同步】
    · 设置窗口右上角新增最小化到任务栏按钮。
    · 歌词偏移可以直接输入 -3000 ~ +3000 ms，保留 0.5 秒快捷微调。
    · 设置项按「歌词」「播放」重新归位；关闭对应显示开关时整页置灰。

  【B 站视频封面】
    · 普通 B 站视频播放时，播放器面板显示视频封面。
    · 无字幕轨的视频也能显示封面；封面按视频地址缓存并自动居中裁切。

v1.6.3  (2026-10-07)

  【歌词和播放对不上：优先用播放器自己家的曲库】
    · 在 QQ音乐 里放歌就优先取 QQ音乐的歌词，网易云就优先网易云，
      酷狗就优先酷狗 —— 同一家的歌词通常就是那个播放器正在显示的
      那一版，时间轴最容易对上（Live 版、剪辑版经常是跨库取词才串的）。
    · 同时加严了「版本筛选」：播放时长已知时，时长差得多的候选
      （比如只有 60 秒的试听版、加上前奏的抖音版）会被明显扣分。
    · 歌词同步多了 ±1 秒档位和「自定义偏移…」（可以直接填毫秒），
      范围放宽到 ±30 秒。

  【前奏期间会告诉你还要等多久】
    · 还没到第一句歌词时，面板上显示「♪ 前奏 · 25 秒后开始」，
      不用干等着怀疑是不是卡住了。
    · 说明一下：歌词本来就是「第一句的时间戳到了才开始滚」，
      所以「等前奏放完再滚」这件事一直是这样做的 ——
      之前之所以觉得对不上，是因为选到了别家版本的歌词，
      第一句的时间戳整体就偏了（这次修的正是它）。
    · 顺带说明为什么不做「听声音自动判断前奏结束」：从音频里只能测出
      「音乐什么时候开始响」，测不出「人声什么时候开始唱」——
      流行歌的前奏里本来就有鼓点和伴奏。要测人声得上语音识别 /
      音源分离模型（几百 MB、很吃 CPU），不适合塞进这个小工具。

  【歌词偏移改成一歌一记了】
    · 以前偏移是「全局」的：给某首对不上的歌调好，下一首本来对得上的
      反而被调歪了。
    · 现在按「**播放器 + 歌名 + 歌手 + 时长**」记：
        - 同名但不同人唱的（翻唱）各记各的，互不影响
        - 同一首歌的不同版本（专辑版 / Live / 剪辑版）时长不同，
          也会分开记
        - 同一首歌在不同播放器里各记一份（时长、歌词版本可能不同，
          分开反而更稳）
    · 菜单里能看出当前在调哪一首：「歌词同步（《我们俩》-2000 ms）」；
      没在放歌时显示「（默认 0 ms）」。
    · **升级时会自动清掉老版本遗留的全局偏移** —— 之前有人在旧版里
      为某一首歌留了个 -6100 ms，升级后它会悄悄套到每一首歌上
      （所有歌的歌词都提前 6 秒）。现在这种情况会自动归零，
      从 0 重新开始，之后每首歌各调各的。
    · 额外给了两个入口：
        「恢复默认（本歌）」——把这一首的调整取消，回到默认值
        「所有歌曲的默认偏移…」——给没单独调过的歌统一设一个值
    · 最多记 300 首，超出后最早的会被丢掉（不会一直占地方）。

  【关于「直接从音乐软件读歌词」】
    · 做不到。Windows 的系统媒体接口（我们读播放状态用的那个）
      只有歌名、歌手、专辑、时长、进度和封面，**不包含歌词**。
    · 直接读播放器的本地歌词文件也不行：实测这台机器上
      Spotify 目录里没有任何歌词文件（歌词是它服务端实时下发的），
      QQ音乐 存的是 .enc/.dat 加密文件，酷狗是 .bin/.dat 私有格式，
      网易云连歌词缓存目录都不存在。就算硬做，也只对个别播放器有效，
      而且播放器一更新就可能失效。

v1.6.2  (2026-10-06)

  【修好了：歌词播到一半不动了】
    · 有些曲库的同名条目只有半首歌的歌词（实测某首 200 秒的歌，
      酷狗只给到 59 秒），以前的逻辑会认下它，结果播到一半
      歌词就停在最后一行不动。
    · 现在会检查「歌词覆盖了多少时长」：覆盖不到 60% 就自动去别的
      曲库换一版完整的。上面那首歌换成 QQ音乐 后覆盖到 88%，正常了。
    · 顺带把歌词缓存版本升级，旧的残缺歌词会重新获取一次。
    · 名字匹配仍然优先：只是名字差一点点但歌词完整的，比名字对得上
      但只有半首的更值得用。
  【纯歌词面板多了歌名、作者和播放热度】
    · 面板顶部显示歌名（大一点、加粗）和「作者 · 专辑」（小一点、淡一点），
      右侧一颗爱心跟着热度值。
    · 歌名、作者、歌词在**同一个倾斜平面**里 —— 上下倾斜、左右倾斜、
      整体旋转会一起作用，看起来是一整块，不会两截。
    · 热度是网易云的 popularity（0~100），查不到就不显示爱心，不会瞎编。
    · 不想要这块可以关掉：右键 →「显示歌名歌手和热度」。
    · 只有独立的「纯歌词面板」显示这块；**分离面板里的歌词列保持原样**，
      仍然只有纯歌词，不加歌名 / 作者 / 热度。

  【倾斜方向可以反过来了】
    · 纯歌词面板 / 分离面板的歌词：上下倾斜多了「下窄上宽」，
      左右倾斜多了「右窄左宽」，弱中强都有。
      （立体卡片保持原样，不受影响）
    · 反方向用的是「两侧对调」，近端放大幅度和原来一样，
      所以窗口不用额外留边，也不会被裁掉。

  【窗口宽度可以自由调】
    · 窗口宽度新增「很窄（400）」「超大（1800）」两档，
      并且多了「自定义宽度…」——想多宽就填多宽（240 ~ 4000）。

  【歌词排版：左对齐 / 居中 / 右对齐】
    · 右键 →「歌词排版」，可以让歌词靠左、居中或者靠右（默认靠右，和以前一致）。
    · 立体卡片和纯歌词面板都生效；纯歌词面板顶部的歌名、作者、
      爱心热度会跟着一起对齐，不会各对各的。

  【打开音乐软件时自动显示歌词】
    · 新增开关（默认开）：一旦检测到音乐软件启动，桌面歌词会自动显示出来，
      不用再去托盘里点一下。
    · 只在你「本来没开音乐软件 → 打开了」这一下动作，不会跟你手动隐藏打架。
    · 识别 QQ音乐 / 网易云 / 酷狗 / 酷我 / Spotify / foobar2000 / PotPlayer
      等常见播放器。

v1.6.1  (2026-10-05)

  【新增：可以导入自己的字体】
    · 右键菜单 → 歌词字体 →「导入字体文件…」，选一个或多个
      ttf / otf / ttc 字体就能用，导入一次以后一直在菜单里。
    · 只导入一个时会自动切换过去，不用再去点一次。
    · 新增「打开字体文件夹」：导入的字体都存在
      %APPDATA%\LyricDesk\fonts，想删掉哪个直接删文件即可。
    · 菜单里导入的字体单独一组，标着「我导入的」，和内置字体、
      系统字体分得清清楚楚。

  【纯歌词 / 分离面板的歌词也能倾斜了】
    · 「上下倾斜」「左右倾斜」「整体旋转」三个菜单不再只属于立体卡片，
      纯歌词面板、分离面板里的歌词列现在都能调，效果和立体卡片完全一致。

  【封面能调得更小】
    · 封面大小新增「很小 / 小」两档，最小可以调到 48。
    · 唱片模式下的唱片整体缩小（原来放得太大），分离面板里默认就小巧不少。

  【修好了：显示封面没反应】
    · 唱片播放器里关掉「显示封面」以前没效果，现在会真的把唱片收起来，
      歌名、歌手、频谱、进度条铺满整行。

  【菜单整理】
    · 删掉了「突起透明度」。
    · 删掉了「设置更新源…」——更新源已经内置，平时用不到；
      万一以后仓库搬家，检查更新失败时弹出的窗口里仍然可以重新设置。
    · 「开机自启」现在明确列出「已开启 / 已关闭」两项，不会再让人误会。

v1.6.0  (2026-10-05)

  【新增：一键更新，点一下自己装好】
    · 检查到新版本时，弹窗里多了一个「立即更新」按钮：
      点它就会自动下载安装程序 → 关闭旧程序 → 静默安装新版 → 自动重新打开。
      全程只需要点这一次，不用再去网页下载和解压。
    · 下载是在后台进行的，下载期间程序照常能用，不卡。
    · 设置、字体、窗口位置、歌词缓存都会保留（它们存在
      %APPDATA%\LyricDesk，和程序文件夹分开）。
    · 已经装了「开始菜单快捷方式」的版本会自动走这条路；
      如果你现在用的是免安装版，点「立即更新」会帮你正式安装一份，
      以后升级就都是自动的了。

  【发行方式调整】
    · 以后只发**安装程序**（双击安装、可在「设置 → 应用」里卸载），
      不再提供免安装压缩包。

v1.5.2  (2026-10-05)

  【新增：检查更新】
    · 右键菜单多了两项：「检查更新…」和「设置更新源…」。
    · 更新源可以填 GitHub 仓库（someone/LyricDesk）、码云仓库
      （gitee:someone/LyricDesk）、一个 JSON 链接，或者本地 JSON 文件。
      程序目录里放一个 update.json 也能直接当更新源（发给朋友时很方便）。
    · 有新版本 → 弹出提示并可以直接打开下载页；已经最新 → 也会明确告诉你。
    · 填好更新源后，启动时会静默自查一次（24 小时内只查一次），
      只有真的出了新版本才发托盘通知。
    · 检查更新走和字体下载同一套代理探测：直连、系统代理、
      常见本地代理端口（7890 / 7897 …）依次尝试；GitHub 源还会自动
      退到国内镜像，所以国内也基本能用。
    · 程序包里附了一份 update.json 模板，改完放到你的仓库/网盘即可。

v1.5.1  (2026-10-05)

  【修好了：纯歌词面板点不动】
    · 上一版选「纯歌词面板」会被自动打回「立体卡片」，界面上看起来就是
      「点了没反应、面板出不来」。原因是保存设置时的校验白名单漏了新模式的
      名字，现在已经补上，并且加了自动检查防止再犯。
    · 顺带把菜单里的「显示背景板」删掉了（现在所有界面都是直接浮在壁纸上，
      用不到这个开关）。

v1.5.0  (2026-10-05)

  【新增：分离面板模式（唱片 + 歌词可以各放各的）】
    · 界面模式新增「分离面板」：唱片播放器和纯歌词变成两扇独立窗口，
      可以分别拖到桌面任意位置，位置都会记住。
    · 第一次切到这个模式时，唱片面板默认落在桌面右上角，
      歌词面板紧贴在它下面。

  【纯歌词面板改成和立体卡片同款】
    · 「纯歌词」= 立体卡片去掉左边专辑，只剩右边的歌词，同样是透明的，
      没有任何背景板，直接浮在壁纸上。

  【菜单整理】
    · 「歌词列表行数」新增「1 行」，歌词面板也能调行数。
    · 删掉了「显示上一行 / 显示下一行」两个选项。
    · 删掉了「背景板不透明度」选项。
    · 删掉了「突起样式」选项（立体卡片的突起固定为最好看的磨砂玻璃效果）。
    · 「整体透明度」改名为「整体不透明度」，命名更准确。
    · 「突起透明度」挪到突起相关设置下面，更容易找到。

  【更好用】
    · 封面大小调大的同时抬高了最小档，最小的封面也不至于太小。
    · 歌词行间距可以单独调，歌词列表更松或更紧凑。
    · 唱片播放器的上一首 / 下一首 / 播放暂停：加大按钮的点击范围，
      并且要拖动 5 像素以上才算移动窗口 —— 以后点切歌不会再误拖窗口。
    · 没识别到播放器时，歌词面板会直接提示：
      「请在音乐软件的设置里开启系统播放控件 / 媒体控制」。
      网易云、酷狗等默认可能是关闭的，打开后才认得到。
    · 鼠标穿透后，用托盘菜单或 Ctrl + Alt + L 都能解除；
      分离面板模式下两扇面板会一起穿透、一起解除。

  【字体】
    · 全部免费字体都打包进程序了：
        得意黑（内置）、霞鹜漫黑（内置）—— 下载完就能直接用，
        不用再联网下载，别人拿到也能正常显示。
    · 华文行楷 / 华文琥珀 / 华文彩云 / 方正舒体 属于微软 Office 自带字体，
      授权不允许随程序分发，所以仍然只在「你系统里装了」的时候才会出现在菜单里；
      没装的话可以用菜单最后的「从系统字体中选择…」或改用内置的两款。

v1.0  (2026-09-27)

  【首次发布】

  · 自动读取 QQ音乐 正在播放的歌曲，在桌面悬浮显示歌词
  · 三种界面模式：
      - 立体卡片：封面方块 + 后方旋转 45° 的淡化方块（只露出四个小三角）
                   + 向内倾斜的歌词列表（默认）
      - 播放器卡片：专辑封面、歌名歌手、进度条、上一首 / 播放暂停 / 下一首
      - 纯歌词：只有歌词，最简洁
  · 歌词逐字渐变高亮，换行时带弹跳动画
  · 五套配色主题：极光、樱花、落日、青竹、素白
  · 文字立体倾斜：上下、左右两个方向各自独立调节，还能整体旋转
  · 突起样式三种：磨砂玻璃 / 封面环境光 / 极简描边
  · 歌词同步微调（整体提前或延后 0.1 / 0.5 秒）
  · 窗口可自由拖动并记住位置，支持锁定、鼠标穿透、置顶
  · 支持开机自启
  · 歌词与专辑封面本地缓存，重复播放不重复下载

  【已知限制】

  · QQ音乐 不向系统上报「可跳转播放位置」，所以进度条只能看、拖动无效
  · 需要 Windows 10 1809 或更高版本
  · 歌词与封面需要联网获取

  【配置与缓存位置】

  %APPDATA%\LyricDesk
     settings.json   设置
     cache\          歌词缓存
     covers\         专辑封面缓存

  删除该目录即可完全重置。卸载程序本身只需删除程序文件夹。
