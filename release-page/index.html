怎么用

  1. 下载安装包 LyricDesk-Setup.exe，双击一路「下一步」装好（不需要管理员权限）。
  2. 装完从开始菜单或桌面图标启动，程序会缩到右下角托盘，桌面出现歌词。
  3. 打开任意音乐软件放歌，歌词会自动跟上；左键拖动摆位置，右键是常用操作菜单（完整设置在「设置…」里）。

常见问题

桌面显示「未检测到正在播放的歌曲」？

不少音乐软件的「系统播放控件 / 媒体控制」默认是关的，关掉之后 Windows 里没有任何播放信息，任何歌词插件都读不到。 到音乐软件设置里打开它即可：网易云 → 设置 → 常规 → 系统媒体控制；酷狗、QQ音乐 等也有类似开关。

怎么关掉 / 怎么退出？

右键桌面上的歌词 → 最小化到托盘，它仍在后台；想彻底退出就右键右下角的音符图标 → 退出。 如果托盘图标被收进「^」溢出区，点一下那个小箭头就能看到。

鼠标穿透之后点不动了？

按 Ctrl + Alt + L 可以随时开关鼠标穿透，也可以右键托盘图标解除。

为什么杀毒软件会提示？

这是 Python 打包的程序，部分杀软对这类自解压程序会误报。程序不联网上传任何数据，歌词和封面只是从公开曲库读取。

以后怎么更新？

程序自带检查更新：右键菜单 → 设置更新源…，把下面的地址填进去，之后每次启动会自动检查一次， 有新版本会提醒你。
