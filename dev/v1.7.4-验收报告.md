## 双光晕

- 近光半径约为字号的 `0.28×`，远光约为 `0.65×`。
- 光晕与入场模糊分别使用 12 条 LRU 缓存。
- 强度 0 / 0.5 / 1 / 2 的整图透明能量：
  `2006435 / 2076562 / 2170095 / 2389232`，严格单调递增。
- 光晕强度 0 或 2 时，off 档像素差为 `0`。
- 截图：`dev/v174_shots/glow-*.png`

## 逐字弹簧

- 每个字素独立维护 waiting / active / passed。
- 弹簧使用 `stiffness=200`、`damping=20` 与 8ms 子步进。
- 单帧缩放夹在 `1.0–1.25`；极端 `dt=0.5s` 仍被夹紧。
- 连续 bounce 帧存在可见变化。
- 截图：`dev/v174_shots/bounce-1..6.png`

## 入场

- normal 行依次经历模糊 10 → 模糊 5 → 原图。
- 同时执行 0.9 → 1.0 缩放和透明度渐入。
- micro 行直接显示。
- 截图：`dev/v174_shots/entry-1..3.png`

## 确定性随机布局

- 同一行重复调用 `_chaos_transform()` 结果完全一致。
- 不同歌词时间的结果不同。
- 两次重绘像素差为 `0`。
- chaos=0.5 时自动宽度从 `543` 增至 `551`，预留偏移空间。
- 圆盘下 chaos 恒为 `(0, 0, 1, 0)`。

## 与计划不同的地方

- 逐字弹簧、入场和随机布局最终合为同一个功能提交：三者在同一个
  绘制入口中共享状态，强行拆开会留下无法单独运行的中间版本。
- 光晕 tint 没有逐帧改变；保持预模糊层本身的三色渐变，只调 alpha。
  这样颜色不会随强度漂移，视觉更稳定。
