# LyricDesk v1.7.0 验收报告

日期：2026-11-06

## 结果

- 歌词准确度：20 首中 19 首通过五项校验；14 首取得逐字时间；首字时间对齐 19/20。明细见 `v1.7.0-歌词准确度样本.md`。
- 网易云：真实 songId 官方 LRC / YRC 解析通过；真机读取到 songId、歌名、歌手和时长。
- 酷狗 KRC：真实《晴天》样本取得 63 行、602 个字级时间点；首字时间全部等于行首。
- 播放控制：12 / 38 / 80 px 字号 × 240 / 380 / 1000 px 宽度九种组合通过；按钮尺寸不超过标题行 1.6 倍。
- 置顶：显示后、启动后 3 秒、10 秒周期重断言均恢复 `WS_EX_TOPMOST`；设置窗口打开期间不会抢回置顶。
- 进度条：拖动 70% 时外部进度不会覆盖预览，拖动期间不发 seek，松手只发一次 seek；拖出进度条松手取消。
- 圆盘：4 / 6 / 14 字 × 左右 × -90 / -45 / 0 / 45 / 90 度共 30 张截图全部可绘制；列表切圆盘 10 次无残留。
- 歌词动效：关闭 / 逐字点亮 / 逐字弹起 / 扫光均可绘制。
- 真实音波：WASAPI 取得 440 Hz 测试音，峰值 0.821；关闭后采集线程数为 0。
- 离屏绘制成本（40 帧平均）：列表 1.55–1.79 ms，圆盘 0.93–1.00 ms；四种动效均低于计划红线。
- 纯 Python 1024 点 FFT：100 帧 0.145 秒。

## 与计划不同

- QQ QRC 按计划中的“可选、最后评估”没有实做：QRC 需要登录态，失败率与维护成本高；本版已经以网易云 YRC 和酷狗 KRC 覆盖逐字需求，其他来源继续回落行级 LRC。
- 圆盘没有做自转；为避免小张角下多行文字互相覆盖，每行仍保持径向，但沿切线方向增加了稳定行距。
- 真实音波在无首帧数据或回环设备不可用时才回落装饰音波；一旦取得数据，静音会真实贴底，不会继续假装跳动。
